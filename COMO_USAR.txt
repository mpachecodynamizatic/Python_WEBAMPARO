═══════════════════════════════════════════════════════════════
  🔧 ENTORNO VIRTUAL (venv)
═══════════════════════════════════════════════════════════════

run.bat ahora usa un entorno virtual Python aislado:

✅ Ventajas:
  • Dependencias separadas del Python del sistema
  • No interfiere con otros proyectos Python
  • Fácil de limpiar y reinstalar

📁 Carpeta creada:
  venv/ (se crea automáticamente la primera vez)

🧹 Limpiar entorno:
  Ejecuta: limpiar_entorno.bat
  (Elimina venv y la base de datos para empezar de cero)

🔄 Reinstalar dependencias:
  Ejecuta: instalar_dependencias.bat
  (O simplemente elimina la carpeta venv y ejecuta run.bat)

═══════════════════════════════════════════════════════════════
  ❓ PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════

Problema: "Python no está instalado"
Solución: Instala Python desde https://www.python.org/
  ⚠️ IMPORTANTE: Marca "Add Python to PATH" al instalar

Problema: "No se pudo crear el entorno virtual"
Solución:
  1. Abre cmd como Administrador
  2. Ejecuta: python -m pip install --upgrade pip
  3. Ejecuta: python -m pip install virtualenv
  4. Intenta ejecutar run.bat nuevamente

Problema: "Error al instalar dependencias"
Solución:
  1. Verifica tu conexión a Internet
  2. Ejecuta: limpiar_entorno.bat
  3. Ejecuta: run.bat nuevamente

Problema: "Puerto 5000/8000 ya en uso"
Solución:
  • run.bat te preguntará si quieres detener el proceso
  • Presiona "S" para detenerlo automáticamente
  • O ejecuta: stop.bat primero

Problema: "Las páginas no se cargan"
Solución:
  - Asegúrate de que run.bat está corriendo
  - Verifica que ambas ventanas de comandos estén abiertas
  - Espera 5-10 segundos después de iniciar
  - Prueba: stop.bat → run.bat

Problema: "No puedo subir imágenes"
Solución:
  - Verifica que la carpeta 'uploads' existe
  - Comprueba que las imágenes sean JPG, PNG o GIF
  - Máximo 10MB por archivo
  - Prueba desde el panel admin

Problema: "Dependencias no se instalan"
Solución:
  1. Ejecuta como Administrador: run.bat
  2. O ejecuta: limpiar_entorno.bat
  3. Luego: instalar_dependencias.bat
